## Internal Call Graph (what the targets depend on)

`init` orchestrates one-time boot setup, in strict order:

1. `frame::init(physical_memory_layout)` — `unsafe`, initializes the frame
   allocator singleton from the supplied bitmap. Must run **first** and **once**.
2. `book_physical_memory_regions(physical_memory_regions)` →
   loops `frame::alloc_range(region)` over each physical region.
3. `book_mmio_regions(mmio_regions)` → for each MMIO region, walks frame-by-frame:
   `hal::platform::gva_to_gpa` → `PhysicalAddress::from_mmio_address` →
   `PageAligned::from_address`, then `if frame::is_covered(phys) { frame::book(phys) }`.
4. `Upool::new()` then `PhysMemoryManager::init(upool)` — builds the user page
   pool and the physical-memory-manager singleton.

Underlying frame-allocator contracts the targets rely on (from `frame.rs`
`#[verus_spec]` on the `Inner` methods):

- `book`: on `Ok`, moves `phys@` from `free_frames` to `allocated_frames` and sets
  `refcounts[phys@] == 1`; on `Err`, state unchanged and `phys@` was not free.
  Requires `self.inv()` and `phys_addr.inv()`, preserves `inv()`.
- `is_covered`: `ret <==> allocated_frames.contains(phys@) || free_frames.contains(phys@)`;
  pure, preserves `inv()`.
- `alloc_range`: books every frame in `[start, start+size)`; requires `region.inv()`,
  preserves `inv()`.
- `frame::init`: establishes the singleton so that `instance().inv()` holds for all
  later operations.

## Caller Expectations

### `pub fn init(physical_memory_regions, mmio_regions, physical_memory_layout) -> Result<(), Error>`

Sole caller: `kernel_vas::init` (the root-VAS boot path), called once during boot.

- **Callers assume on `Ok(())`:**
  - The frame allocator singleton is fully initialized and globally usable; every
    subsequent `frame::*`/`PhysMemoryManager::*` call may assume `instance().inv()`.
  - All frames covered by `physical_memory_regions` are reserved (booked), so
    `alloc()` will never hand out a frame backing reserved physical RAM.
  - All MMIO frames that the allocator actually tracks (`is_covered == true`) are
    booked; MMIO above RAM (untracked) is silently skipped — callers rely on this
    "skip-if-not-covered" behavior so a high LAPIC address does not abort boot.
  - The user page pool (`Upool`) and `PhysMemoryManager` singleton are initialized
    and ready; `kernel_vas::init` proceeds to build page tables immediately after.
  - `init` ran exactly once (it consumes `physical_memory_regions` and the
    `Bitmap` by value; `frame::init` rejects a second call via `INSTANCE_INIT`).
- **Callers assume on `Err(e)`:** boot fails and propagates `?`; `kernel_vas::init`
  does not attempt recovery or partial use of the physical memory manager. No
  guarantee about partially-booked state is consumed by the caller — failure is
  terminal for the boot path.
- **Would break the caller if changed:** the post-condition that the frame
  allocator + `PhysMemoryManager` are initialized and that reserved/MMIO frames
  are booked; the ordering guarantee (allocator before any allocation); the
  by-value/once semantics; the "skip untracked MMIO" tolerance.
- **Callers do NOT care about:** the internal split into `book_physical_memory_regions`
  vs `book_mmio_regions`; the per-region iteration order; logging (`info!`); the
  concrete bitmap/refcount representation; that MMIO booking walks frame-by-frame;
  whether `Upool::new` precedes or follows region booking.

### `fn book_physical_memory_regions(physical_memory_regions) -> Result<(), Error>` (private)

Caller: `init` only.

- **Assumes on `Ok`:** every frame in every region of the list is booked
  (`alloc_range` succeeded for all), so those frames are now allocated and excluded
  from future `alloc()`.
- **Assumes on `Err`:** booking stopped at the first failing region; `init`
  short-circuits via `?` and the whole boot fails. Partial booking is acceptable
  because the only consumer treats `Err` as fatal.
- **Caller does NOT care about:** iteration order, logging, the fact it consumes the
  list by value.

### `fn book_mmio_regions(mmio_regions) -> Result<(), Error>` (private)

Caller: `init` only.

- **Assumes on `Ok`:** every MMIO frame that the allocator tracks
  (`is_covered`) is booked; untracked MMIO frames are intentionally skipped (not an
  error). The GVA→GPA translation and page-alignment of each MMIO frame succeeded.
- **Assumes on `Err`:** an MMIO address failed translation/validation
  (`from_mmio_address`, `from_address`) or a tracked frame failed to book; `init`
  fails. Borrows the list (`&`), so the caller still owns it afterward.
- **Caller does NOT care about:** the frame-by-frame walk granularity
  (`mem::FRAME_SIZE` stepping), the `gva_to_gpa` mechanism, or logging.

## Abstract Resource

From the caller's perspective this module manages the **global physical-memory
reservation state at boot**: it transitions the system from "frame allocator
uninitialized" to "frame allocator + physical memory manager initialized, with all
reserved physical-RAM frames and all tracked MMIO frames booked so they will never
be handed out by the general allocator." The key operation callers use is the
one-shot `init`; the abstract effect is "establish the `FrameAllocView` invariant
and pre-reserve the boot-known frames."

## Key Invariants (caller perspective)

- **Establishes, not just preserves, the allocator invariant:** after `Ok`,
  `instance().inv()` (i.e. `FrameAllocView::wf`) holds for all later `mm::phys`
  operations. This is the precondition every other frame/manager function requires.
- **Reserved frames are excluded from allocation:** all frames in
  `physical_memory_regions` and all tracked MMIO frames are moved into
  `allocated_frames` with `refcount == 1`; they are disjoint from `free_frames`.
- **Untracked MMIO is tolerated:** `is_covered == false` ⇒ skip; not booking such a
  frame is correct behavior, not an error.
- **One-shot / monotonic init:** `init` runs exactly once; a second call is rejected
  by `frame::init` (`INSTANCE_INIT`). Callers never invoke it twice.
- **Failure is terminal:** on `Err`, callers abandon the boot path; no contract is
  offered about partially-booked intermediate state.

### Assessment

- **Coverage:** partial. The View and per-frame operation contracts are in place,
  but the boot-orchestration layer (`mod.rs`) is unspecified.
- **Strength:** the `Inner`-method ensures are adequate (cover both `Ok` and `Err`
  state transitions and preserve `inv()`). They give `init` everything it needs to
  prove its own postcondition once the free-function wrappers are given thin
  pass-through specs.

  only cares that reserved/MMIO frames end up allocated. No View field appears

  `FrameAllocView`.
