**Design summary** — `PhysMemView` for the boot-orchestration layer (`init`, `book_physical_memory_regions`, `book_mmio_regions`), which operate on the global frame-allocator singleton:

```rust
pub struct PhysMemView {
    pub initialized: bool,        // lifecycle: has init run once (Ok)
    pub frames: FrameAllocView,   // reused: reserved/free frames + refcounts
}
```

Key decisions:
- **Two fields only.** `frames` reuses the out-of-scope `FrameAllocView` (so the verified `book`/`alloc_range` post-states compose directly); `initialized` adds the one dimension `FrameAllocView` *cannot* express — the uninit→init lifecycle that is central to `init`'s "establishes `wf`" / one-shot contract.
- **`inv`:** `initialized ==> frames.wf()`.
- **Spec transitions:** `spec_initialize`, `spec_book_frame`, `spec_book_frames`, plus helpers `covered()` and `region_frames()`. MMIO skip-untracked is captured declaratively as `spec_book_frames(M.intersect(covered()))`.
