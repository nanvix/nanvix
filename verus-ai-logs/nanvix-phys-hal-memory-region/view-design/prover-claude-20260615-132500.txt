Summary of the design:

**Abstract resource:** a non-wrapping half-open byte interval `[start, start+size)` + metadata tags. The `TruncatedMemoryRegion` is the same interval with page-aligned endpoints.

**View** (`MemoryRegionView`, shared by both region types, addresses as `int`):
- `start: int`, `size: int` — the geometry the four in-scope accessors expose
- `typ`, `perm`, `cache_policy` — caller-observable metadata tags

**inv():** keeps the existing page-alignment clauses on `TruncatedMemoryRegion` and adds a shared `wf_geometry` (size ≥ 1, no-wrap `start+size ≤ usize::MAX+1`) — the facts callers depend on for `size-1`, `size/FRAME_SIZE`, inclusive-end math.

**Spec transition:** only `set_cache_policy` mutates, so a single `spec_set_cache_policy` with `..self` frame condition. Accessors are pure reads owing `result@ == self@.start` / `result == self@.size`.

**Rejected:** `name` (unused → minimality), typed/`usize`/`nat` address types (overflow/abstraction), stored `end`, a separate truncated View, and a kind tag (type-system fact as spec).

Every field passes the substitution test — all describe intrinsic region state independent of storage/truncation strategy. The omitted `name` and the closed `view()` forwarding keep the abstraction caller-focused.
