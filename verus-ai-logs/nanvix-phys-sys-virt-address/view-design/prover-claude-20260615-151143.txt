**Abstract resource:** `VirtualAddress` is an opaque pointer-sized integer naming one byte location in a virtual address space — to callers it *is* its raw `usize`, with no extra state.

**View:** scalar `type V = int`, `closed view(&self) -> int` (kept from the existing inline skeleton, consistent with the rest of the address tower). Single abstract field = the raw address.

- `new` / inherent `from_raw_value`: `result@ == arg as int && result.inv()`
